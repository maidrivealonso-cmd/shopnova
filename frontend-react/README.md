# ShopNova - módulo front-end en React

Este módulo se agregó dentro del proyecto existente ShopNova. Los archivos HTML, CSS, JavaScript y el módulo Java original se conservan en la carpeta principal.

## Requisitos
- Node.js instalado
- Conexión a internet la primera vez para instalar las dependencias de React y Vite

## Cómo ejecutar
1. Abre Visual Studio Code.
2. Abre la carpeta `shopnova`.
3. Abre Terminal > Nueva terminal.
4. Ejecuta:
   `cd frontend-react`
5. Ejecuta:
   `npm install`
6. Cuando termine, ejecuta:
   `npm run dev`
7. Abre en el navegador la dirección local que muestre la terminal.

## Funciones incluidas en el prototipo React
- Inicio y catálogo de camisetas.
- Búsqueda por nombre.
- Detalle de producto con talla, color y cantidad.
- Carrito guardado en localStorage, cambio de cantidad y eliminación.
- Formularios de inicio de sesión y registro.
- Resumen de pedido y pantalla de confirmación de demostración.

## Importante
Los formularios de inicio de sesión y registro de esta versión React validan los campos en el navegador, pero todavía no están conectados al servidor Java/MySQL. La confirmación de pedido es una demostración del flujo del front-end. El proyecto original y su módulo Java se conservan por separado.
